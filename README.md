# سیستم شباهت‌یابی مبتنی بر شبکه عصبی (کارآموزی)

پروژه کارآموزی برای ساخت پایگاه‌داده بازه‌ای، تولید داده‌های دریافتی نقطه‌ای با طول متغیر از درون بازه‌ها و یافتن ۳ سطر با بیشترین شباهت با استفاده از شبکه عصبی عمیق، همراه با حل مسئله گلوگاه طول متغیر، تشخیص نمونه‌های خارج از پایگاه‌داده (Out-of-Distribution)، و گزارش گرافیکی ۳ بعدی و ۲ بعدی همپوشانی کلاسترها.

---

## ویژگی‌ها و نوآوری‌ها مطابق کلیه نیازمندی‌های کارفرما

1. **فایل تنظیمات متمرکز (`config.txt`):**
   تمام پارامترهای ثابت پروژه (شامل ابعاد دیتابیس، بازه‌ها، نرخ نویز، احتمال غیبت، آستانه شباهت ۳۰٪، لایه‌های شبکه و مسیر فایل‌ها) در یک فایل `config.txt` قرار داشته و بدون دستکاری در کدها قابل تنظیم هستند.
2. **تحلیل گرافیکی ۳ بعدی و ۳ نمای ۲ بعدی همپوشانی کلاسترها (`database_3d_visualization.png`):**
   نمایش ۳ بعدی وضعیت دیتابیس به همراه ۳ نمودار ۲ بعدی از فرافکنی پارامترها ($F_1-F_2$، $F_1-F_3$، $F_2-F_3$) و نمایش پوسته‌های محدب کلاسترها جهت تحلیل بصری دقیق همپوشانی‌ها (حداکثر همپوشانی ۱۴.۲۵٪ که کمتر از سقف ۳۰٪ است).
3. **معیار شباهت مطلق غیرنسبی به پایگاه‌داده (Absolute Similarity):**
   خروجی شبکه مقید به جمع ۱۰۰٪ (Softmax کاذب) نیست؛ بلکه درصد انطباق دقیق داده ورودی با بازه‌های پایگاه‌داده را نشان می‌دهد.
4. **آزمون رسمی داده‌های خارج از دیتابیس (OOD Validation) و شرط آستانه ۳۰٪ (`test_out_of_distribution.py`):**
   هر داده‌ای که شباهت آن به پایگاه‌داده کمتر از ۳۰٪ باشد، با صراحت به عنوان **«عدم وجود در پایگاه‌داده»** علامت‌گذاری و رد می‌شود.
5. **بلوک دیاگرام معماری شبکه عصبی (`network_architecture_diagram.png`):**
   شماتیک کامل از فرآیند دریافت داده متغیر $\to$ نرمال‌سازی و پدینگ ماسک‌دار $\to$ لایه‌های متراکم و گیتینگ عصبی $\to$ لایه شباهت مطلق و تصمیم‌گیری.
6. **حذف مستقل ۳۰٪ برای هر یک از اعضای بردار ویژگی (Independent Dropout):**
   هر عضو به صورت مستقل با احتمال ۳۰٪ می‌تواند مفقود باشد و توسط شبکه عصبی با موفقیت مدیریت می‌شود.
7. **کد مجزای استنتاج سریع با بارگذاری وزن‌ها (`inference.py`):**
   وزن‌های مدل در فایل `trained_model.joblib` ذخیره شده و توسط اسکریپت `inference.py` در کسری از ثانیه (کمتر از ۰.۰۵ ثانیه) بدون نیاز به آموزش مجدد اجرا می‌شوند.
8. **نمودارهای ارزیابی دقت عملکرد آموزش و آزمون (`accuracy_evaluation_plot.png`):**
   دقت بیش از ۹۵٪ در ۳ سطر برتر (Top-3 Accuracy: 95.94%).

## ساختار فایل‌های پروژه

| فایل | توضیح |
|------|-------|
| `config.txt` | **فایل پیکربندی متمرکز تمام پارامترها و مسیرهای پروژه** |
| `config_utils.py` | ماژول لودر و پارسر تنظیمات `config.txt` برای کلیه اسکریپت‌ها |
| `generate_database.py` | ساخت پایگاه‌داده ۱۰۰ سطری بر اساس بازه‌ها با سقف همپوشانی ۳۰٪ |
| `visualize_database.py` | تولید نمودار ۴ پانله ۳ بعدی و ۳ نمای ۲ بعدی همپوشانی کلاسترها |
| `generate_query.py` | تولید داده ورودی با حذف مستقل ۳۰٪ برای هر یک از اعضا و نویز ۱٪ |
| `similarity_nn.py` | آموزش شبکه عصبی، ارزیابی دقت و ذخیره وزن‌های مدل |
| `inference.py` | **استنتاج سریع با بارگذاری وزن‌ها و محاسبه شباهت مطلق به پایگاه‌داده** |
| `test_out_of_distribution.py` | **آزمون اعتبارسنجی داده‌های خارج از پایگاه‌داده و آستانه ۳۰٪** |
| `pipeline.ipynb` | نوت‌بوک تعاملی ژوپیتر ۱۲ سلولی شامل تمام مراحل پروژه |
| `TRAINING_DOC.md` | مستند جامع فنی، تئوری و پاسخ‌های تفصیلی به درخواست‌های کارفرما |
| `network_architecture_diagram.png` | تصویر بلوک دیاگرام ساختار و معماری شبکه عصبی |
| `database_3d_visualization.png` | تصویر ۴ پانله ۳ بعدی و ۲ بعدی همپوشانی پایگاه‌داده |
| `accuracy_evaluation_plot.png` | تصویر نمودارهای دقت آموزش و تست و منحنی همگرایی |
| `trained_model.joblib` | فایل وزن‌های ذخیره‌شده شبکه عصبی |
| `database.csv` / `.pkl` / `.json` | فایل‌های ذخیره‌سازی پایگاه‌داده |
| `query.json` / `query.txt` | فایل نمونه داده ورودی معتبر |
| `query_ood_test.json` | فایل نمونه داده ورودی خارج از پایگاه‌داده |
| `top3_results.json` | نتایج ۳ سطر شبیه‌ترین به همراه درصد شباهت مطلق |

## راهنمای اجرا

### گام ۰: فعال‌سازی محیط مجازی
```bash
source venv/bin/activate
```

### ۱. اجرای استنتاج سریع با وزن‌های ذخیره‌شده (بدون آموزش مجدد)
```bash
python inference.py
```

### ۲. اجرای آزمون تشخیص داده خارج از پایگاه‌داده (Out-of-Distribution)
```bash
python test_out_of_distribution.py
```

### ۳. تولید تصویر ۳ بعدی و ۳ نمای ۲ بعدی همپوشانی پایگاه‌داده
```bash
python visualize_database.py
```

### ۴. آموزش مجدد شبکه عصبی و به‌روزرسانی وزن‌ها و نمودارها
```bash
python similarity_nn.py
```

### ۵. اجرای نوت‌بوک تعاملی ژوپیتر (Jupyter Notebook)
```bash
jupyter notebook pipeline.ipynb
```
