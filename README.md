# سیستم شباهت‌یابی مبتنی بر شبکه عصبی (کارآموزی)

پروژه کارآموزی برای ساخت پایگاه‌داده بازه‌ای، تولید داده‌های دریافتی نقطه‌ای با طول متغیر از درون بازه‌ها و یافتن ۳ سطر با بیشترین شباهت با استفاده از شبکه عصبی عمیق.

---

## ویژگی‌ها و نوآوری‌های معماری مطابق بازخورد کارفرما

1. **حل گلوگاه ورودی با طول متغیر با رویکرد پدینگ و ماسک اعتبار (Padding & Validity Masking):**
   بدون نیاز به خلاصه‌سازی یا تبدیل داده‌ها به پارامترهای آماری (مانند میانگین، انحراف معیار یا F1)، بردار داده‌های ورودی با طول متغیر مستقیماً همراه با بردار ماسک دودویی وارد لایه‌های شبکه عصبی عمیق می‌شوند.
2. **استنتاج مستقیم بدون جستجو در پایگاه‌داده (Zero Database Search during Inference):**
   در مرحله استنتاج هیچ حلقه یا مقایسه دستی با سطرهای پایگاه‌داده صورت نمی‌گیرد؛ شبکه عصبی به عنوان یک طبقه‌بند ۱۰۰ کلاسه آموزش دیده و در یک گذر مستقیم (One Forward Pass)، توزیع احتمالاتی کامل (Softmax) روی تمامی ۱۰۰ سطر پایگاه‌داده را خروجی می‌دهد.
3. **داده‌های ورودی نقطه‌ای خالص (Point Values):**
   داده‌های ورودی به شبکه بازه‌ای نیستند و به صورت مقادیر عددی تصادفی از درون بازه‌ها با ۱٪ نویز و ۳۰٪ شانس حذف عضو استخراج می‌شوند.
4. **مستندات کامل در [TRAINING_DOC.md](TRAINING_DOC.md):**
   تشریح دقیق مبانی نظری حل گلوگاه طول متغیر در یادگیری عمیق، لایه‌های شبکه و روند آموزش و استنتاج.

---

## ساختار پروژه

| فایل | توضیح |
|------|-------|
| `generate_database.py` | ساخت پایگاه‌داده ۱۰۰ سطری بر اساس بازه‌ها (Feature1, Feature2, Feature3) |
| `generate_query.py` | تولید داده ورودی نقطه‌ای با طول متغیر از درون بازه‌ها (با ۱٪ نویز و ۳۰٪ احتمال حذف عضو) |
| `similarity_nn.py` | الگوریتم شباهت‌یابی مستقیم با شبکه عصبی عمیق و گزارش ۳ سطر برتر به همراه احتمال |
| `pipeline.ipynb` | نوت‌بوک تعاملی ژوپیتر شامل اجرای گام‌به‌گام و سلولی تمام مراحل پروژه |
| `TRAINING_DOC.md` | مستند کامل نحوه حل گلوگاه ورودی با طول متغیر، تولید داده آموزشی و فرآیند یادگیری |
| `database.csv` / `.pkl` / `.json` | فایل‌های پایگاه‌داده ۱۰۰ سطری |
| `query.json` / `query.txt` | نمونه داده ورودی تولیدشده (مقادیر عددی بدون بازه) |
| `top3_results.json` | نتایج ۳ سطر شبیه‌ترین به همراه درصد احتمال شباهت دقیق |

## نحوه اجرا

### روش اول: اجرای اسکریپت‌های پایتون در ترمینال

```bash
# فعال‌سازی محیط مجازی
source venv/bin/activate   # در ویندوز: venv\Scripts\activate

# اجرای مرحله ۱: ساخت پایگاه‌داده بازه‌ای (در صورت نیاز مجدد)
python generate_database.py

# اجرای مرحله ۲: تولید نمونه داده دریافتی نقطه‌ای با طول متغیر
python generate_query.py

# اجرای مرحله ۳: آموزش شبکه عصبی و یافتن ۳ سطر با بیشترین شباهت
python similarity_nn.py
```
