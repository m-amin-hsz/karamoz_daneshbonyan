# سیستم شباهت‌یابی مبتنی بر شبکه عصبی (کارآموزی)

پروژه کارآموزی برای ساخت پایگاه‌داده بازه‌ای، تولید داده‌های دریافتی نقطه‌ای با طول متغیر از درون بازه‌ها و یافتن ۳ سطر با بیشترین شباهت با استفاده از شبکه عصبی عمیق.

---

## ویژگی‌ها و نوآوری‌های معماری مطابق بازخورد و اصلاحات کارفرما

1. **حذف مستقل ۳۰٪ برای هر یک از اعضای بردار ویژگی (Independent Dropout):**
   هر عضو به صورت تصادفی و مستقل با احتمال ۳۰٪ می‌تواند مفقود باشد و توسط شبکه عصبی با موفقیت مدیریت می‌شود.
2. **کد مجزای استنتاج سریع با بارگذاری وزن‌ها (`inference.py`):**
   جهت صرفه‌جویی در زمان، وزن‌های آموزش‌دیده در فایل `trained_model.joblib` ذخیره شده و توسط اسکریپت `inference.py` در کمتر از ۰.۱ ثانیه لود و اجرا می‌شوند (بدون نیاز به ترین مجدد).
3. **نمایش گرافیکی ۳ بعدی و تحلیل همپوشانی پایگاه‌داده (`database_3d_visualization.png`):**
   توزیع مکانی ۱۰۰ سطر در فضای ۳ بعدی ویژگی‌ها و ماتریس گرمایی همپوشانی دوبه‌دو (حداکثر ۳۰٪ مطابق صورت‌مسئله).
4. **نمودارهای تفصیلی دقت عملکرد آموزش و آزمون (`accuracy_evaluation_plot.png`):**
   رسم منحنی همگرایی تابع هزینه، منحنی اعتبارسنجی و نمودار میله‌ای مقایسه‌ای دقت در آموزش و تست (دقت بیش از ۹۵٪ در ۳ سطر برتر).
5. **حل گلوگاه ورودی با طول متغیر با رویکرد پدینگ و ماسک اعتبار (Padding & Validity Masking):**
   بدون نیاز به خلاصه‌سازی یا تبدیل داده‌ها به پارامترهای آماری (مانند میانگین یا F1) و بدون سرچ دستی روی دیتابیس.

## ساختار پروژه

| فایل | توضیح |
|------|-------|
| `generate_database.py` | ساخت پایگاه‌داده ۱۰۰ سطری بر اساس بازه‌ها (Feature1, Feature2, Feature3) |
| `visualize_database.py` | تولید تصویر ۳ بعدی پایگاه‌داده و ماتریس همپوشانی (`database_3d_visualization.png`) |
| `generate_query.py` | تولید داده ورودی با حذف مستقل ۳۰٪ برای هر یک از اعضا و ۱٪ نویز |
| `similarity_nn.py` | آموزش شبکه عصبی عمیق، ارزیابی، رسم نمودارها و ذخیره وزن‌های مدل |
| `inference.py` | **کد مجزای استنتاج سریع با استفاده از وزن‌های ذخیره‌شده (بدون آموزش مجدد)** |
| `pipeline.ipynb` | نوت‌بوک تعاملی ژوپیتر شامل تمام مراحل بالا به همراه نمایش نمودارها و نتایج |
| `TRAINING_DOC.md` | مستند جامع تئوری و نتایج دقت و معماری شبکه |
| `trained_model.joblib` | فایل باینری وزن‌های مدل آموزش‌دیده |
| `database_3d_visualization.png` | تصویر گرافیکی ۳ بعدی پایگاه‌داده و تحلیل همپوشانی |
| `accuracy_evaluation_plot.png` | نمودارهای تصویری دقت آموزش/تست و همگرایی تابع هزینه |
| `database.csv` / `.pkl` / `.json` | فایل‌های پایگاه‌داده ۱۰۰ سطری |
| `query.json` / `query.txt` | نمونه داده ورودی تولیدشده (مقادیر عددی بدون بازه) |
| `top3_results.json` | نتایج ۳ سطر شبیه‌ترین به همراه درصد احتمال شباهت دقیق |

## نحوه اجرا

### روش اول: اجرای استنتاج سریع با وزن‌های ذخیره‌شده (توصیه‌شده برای تست فوری)

```bash
# فعال‌سازی محیط مجازی
source venv/bin/activate

# اجرای استنتاج فوری بدون نیاز به آموزش مجدد (اجرا در کسری از ثانیه)
python inference.py
```

### روش دوم: اجرای کامل پایپ‌لاین در ترمینال

```bash
# ۱. تولید پایگاه‌داده بازه‌ای
python generate_database.py

# ۲. تولید نمودار ۳ بعدی پایگاه‌داده و همپوشانی
python visualize_database.py

# ۳. تولید داده ورودی تصادفی (کوئری)
python generate_query.py

# ۴. آموزش شبکه عصبی، ذخیره وزن‌ها و رسم نمودارهای دقت
python similarity_nn.py
```

### روش سوم: اجرای تعاملی در ژوپیتر نوت‌بوک

```bash
jupyter notebook pipeline.ipynb
```
