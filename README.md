# سیستم شباهت‌یابی مبتنی بر شبکه عصبی (کارآموزی)

پروژه کارآموزی برای ساخت پایگاه‌داده بازه‌ای، تولید داده‌های دریافتی نقطه‌ای از درون بازه‌ها و یافتن ۳ سطر با بیشترین شباهت با استفاده از شبکه عصبی MLP.

---

## اصلاحات انجام‌شده مطابق بازخورد کارفرما

1. **اصلاح داده‌های ورودی به شبکه (Query):**
   داده‌های ورودی دیگر به صورت بازه‌ای (`a-b`) نیستند، بلکه مقادیر عددی نقطه‌ای هستند که به صورت تصادفی از درون بازه‌های پایگاه‌داده انتخاب شده‌اند و دارای ۱٪ نویز و احتمال ۳۰٪ حذف عضو هستند.
2. **داکیومنت جامع نحوه تولید و ورودی دادن به شبکه:**
   یک مستند کامل در فایل [TRAINING_DOC.md](TRAINING_DOC.md) اضافه شده است که نحوه تولید داده‌های آموزشی، مدل‌سازی ریاضی تطابق نقطه با بازه، و نحوه ورودی دادن به شبکه عصبی MLP را به طور دقیق شرح می‌دهد.

---

## ساختار پروژه

| فایل | توضیح |
|------|-------|
| `generate_database.py` | ساخت پایگاه‌داده ۱۰۰ سطری بر اساس بازه‌ها (Feature1, Feature2, Feature3) |
| `generate_query.py` | تولید داده ورودی نقطه‌ای تصادفی از درون بازه‌ها (با ۱٪ نویز و ۳۰٪ احتمال حذف عضو) |
| `similarity_nn.py` | الگوریتم شباهت‌یابی با شبکه عصبی MLP و گزارش ۳ سطر برتر به همراه احتمال |
| `TRAINING_DOC.md` | مستند کامل نحوه تولید داده آموزشی و شیوه ورودی دادن به شبکه عصبی |
| `database.csv` / `.pkl` / `.json` | فایل‌های پایگاه‌داده ۱۰۰ سطری |
| `query.json` / `query.txt` | نمونه داده ورودی تولیدشده (مقادیر عددی بدون بازه) |
| `top3_results.json` | نتایج ۳ سطر شبیه‌ترین به همراه درصد احتمال شباهت |

---

## نحوه اجرا

```bash
# فعال‌سازی محیط مجازی
source venv/bin/activate   # در ویندوز: venv\Scripts\activate

# اجرای مرحله ۱: ساخت پایگاه‌داده بازه‌ای (در صورت نیاز مجدد)
python generate_database.py

# اجرای مرحله ۲: تولید نمونه داده دریافتی نقطه‌ای از درون بازه‌ها
python generate_query.py

# اجرای مرحله ۳: آموزش شبکه عصبی و یافتن ۳ سطر با بیشترین شباهت
python similarity_nn.py
```
